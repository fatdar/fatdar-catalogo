# FATDAR — guía rápida de la hoja

**[Abrir el Google Sheet de FATDAR](https://docs.google.com/spreadsheets/d/1TQM0CIUP1Zt9B7Bv1vr3Pdz4CDXXjQhWx8_ZBqYcTPo/edit)**

Para el uso diario solo verás dos pestañas: **Productos** y **Precios**. `Configuracion` seguirá oculta y preservada para que la tienda conserve su diseño, idiomas y SEO; no necesitas abrirla ni editarla.

## Agregar o quitar productos

1. En **Productos**, agrega una fila debajo de los encabezados.
2. Completa **ID** (único), **Producto**, **Categoría**, **Descripción**, **Foto URL** y **Activo**.
3. Escoge una categoría del menú: Android, iOS, Diamantes, Fragmentos de armas, Pases, Números virtuales o Modificaciones iOS.
4. Pon **Activo = Sí** para mostrar el artículo o **No** para ocultarlo sin perder la fila. Para borrarlo definitivamente, elimina la fila.
5. La foto debe tener un enlace público de lectura; puedes usar un enlace de Google Drive compartido para lectura.

## Cambiar o quitar precios

1. En **Precios**, cada fila representa una opción para un producto.
2. Copia en **ID del producto** el mismo ID que aparece en **Productos**.
3. Edita **Opción**, **Precio (COP)** y **Duración**; escribe el precio como número, sin símbolo de moneda.
4. Para ofrecer otra alternativa, agrega una nueva fila con el mismo ID. Pon **Activo = No** para ocultar una opción sin borrarla; elimina la fila solo si quieres borrarla definitivamente.

Las columnas de traducción inglesa están ocultas a la derecha para mantener la vista sencilla; aparecen en la versión inglesa si luego las completas. No agregué productos, fotos, precios ni duraciones ficticias: al llenar estas dos pestañas, la tienda organizará los artículos automáticamente por categoría.
